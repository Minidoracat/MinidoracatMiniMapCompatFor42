description=[h2]✨ What is this?[/h2]
description=A third-party MOD [b]compatibility pack[/b] for [b]Minidoracat MiniMap for B42[/b].
description=When a supported MOD is enabled, this pack adds its verified animal group to the main MOD's
description=species filter as a named compatibility entry with its own toggle.
description=[list]
description=[*] Quietly does nothing when the corresponding third-party MOD is not enabled
description=[*] Uses vanilla map assets; it does not copy or repackage third-party code, models, textures, or sounds
description=[*] Does not replace third-party markers; each compatibility icon can be disabled in the main MOD's species filter
description=[/list]
description=
description=[h2]🐕 Currently supported[/h2]
description=[list]
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3740052292]Companion Dogs [ALPHA][/url] (Mod ID: [b]CompanionDogs[/b])
description=[/list]
description=
description=With Companion Dogs enabled, “Dogs (loaded nearby)” appears in the main MOD's animal species
description=filter. When the main MOD's animal icons are enabled, nearby loaded animals in the [b]dog[/b] group
description=use the vanilla paw-print icon. The main MOD already uses paw prints for unknown groups; this pack
description=adds the verified Dogs label and a dedicated toggle.
description=
description=[b]Important:[/b] Companion Dogs' own active/passive companion markers continue to work normally.
description=Animal icons in the main MOD are off by default, so generic icons are not added by default. If you
description=enable them but only want the upstream markers, untick “Dogs” in the main MOD's animal filter.
description=
