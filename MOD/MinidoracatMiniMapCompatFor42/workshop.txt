description=[h2]✨ What is this?[/h2]
description=A third-party MOD [b]compatibility pack[/b] for [b]Minidoracat MiniMap for B42[/b].
description=When a supported MOD is enabled, this pack adds its verified animal group to the main MOD's
description=species filter as a named compatibility entry with its own toggle.
description=[list]
description=[*] Quietly does nothing when the corresponding third-party MOD is not enabled
description=[*] Uses vanilla symbols and original icons made for this pack; it does not copy or repackage third-party code, models, textures, or sounds
description=[*] Does not replace third-party markers; each compatibility icon can be disabled in the main MOD's species filter
description=[/list]
description=
description=[h2]🐕🐎 Currently supported[/h2]
description=[list]
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3740052292]Companion Dogs [ALPHA][/url] (Mod ID: [b]CompanionDogs[/b])
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3661336777]Horse Mod [B42.14+/MP SOON][/url] (Mod ID: [b]Horse[/b])
description=[/list]
description=
description=With Companion Dogs enabled, “Dogs (loaded nearby)” appears in the main MOD's animal species
description=filter. When the main MOD's animal icons are enabled, nearby loaded animals in the [b]dog[/b] group
description=use either the vanilla paw-print symbol or this pack's original colored dog icon, depending on the
description=selected icon style. This pack also adds the verified Dogs label and a dedicated toggle.
description=
description=[b]Important:[/b] Companion Dogs' own active/passive companion markers continue to work normally.
description=Animal icons in the main MOD are off by default, so generic icons are not added by default. If you
description=enable them but only want the upstream markers, untick “Dogs” in the main MOD's animal filter.
description=
description=With Horse Mod enabled, “Horses (loaded nearby)” appears in the species filter. Nearby loaded animals
description=in the [b]horse[/b] group use this pack's original horse-head symbol or colored horse icon. This pack
description=only displays them; it does not change spawning, AI, equipment, riding, or include Horse Mod assets.
description=
description=[b]Multiplayer note:[/b] The compatibility pack itself can run in multiplayer, but Horse Mod is
description=currently labelled [b]MP SOON[/b] and its description states that riding is not yet supported in MP.
description=This compatibility feature does not change or bypass those upstream limitations.
description=
