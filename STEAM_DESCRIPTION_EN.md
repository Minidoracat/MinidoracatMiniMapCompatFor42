[h2]✨ What is this?[/h2]
A third-party MOD [b]compatibility pack[/b] for [b]Minidoracat MiniMap for B42[/b].
When a supported MOD is enabled, this pack adds its verified animal group to the main MOD's
species filter as a named compatibility entry with its own toggle.
[list]
[*] Quietly does nothing when the corresponding third-party MOD is not enabled
[*] Uses vanilla symbols and original icons made for this pack; it does not copy or repackage third-party code, models, textures, or sounds
[*] Does not replace third-party markers; each compatibility icon can be disabled in the main MOD's species filter
[/list]

[h2]🐕🐎 Currently supported[/h2]
[list]
[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3740052292]Companion Dogs [ALPHA][/url] (Mod ID: [b]CompanionDogs[/b])
[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3661336777]Horse Mod [B42.14+/MP SOON][/url] (Mod ID: [b]Horse[/b])
[/list]

With Companion Dogs enabled, “Dogs (loaded nearby)” appears in the main MOD's animal species
filter. When the main MOD's animal icons are enabled, nearby loaded animals in the [b]dog[/b] group
use either the vanilla paw-print symbol or this pack's original colored dog icon, depending on the
selected icon style. This pack also adds the verified Dogs label and a dedicated toggle.

[b]Important:[/b] Companion Dogs' own active/passive companion markers continue to work normally.
Animal icons in the main MOD are off by default, so generic icons are not added by default. If you
enable them but only want the upstream markers, untick “Dogs” in the main MOD's animal filter.

With Horse Mod enabled, “Horses (loaded nearby)” appears in the species filter. Nearby loaded animals
in the [b]horse[/b] group use this pack's original horse-head symbol or colored horse icon. This pack
only displays them; it does not change spawning, AI, equipment, riding, or include Horse Mod assets.

[b]Multiplayer note:[/b] The compatibility pack itself can run in multiplayer, but Horse Mod is
currently labelled [b]MP SOON[/b] and its description states that riding is not yet supported in MP.
This compatibility feature does not change or bypass those upstream limitations.

[h2]🙏 Original authors & asset boundary[/h2]
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3661336777]Horse Mod[/url] is made by its original author team.

[h2]💡 Want another MOD supported?[/h2]
Post the third-party MOD's Workshop link and the object type you want displayed in the [url=https://steamcommunity.com/workshop/filedetails/discussion/3765182411/574921459914281992/]Compatibility Requests discussion[/url].

and compatibility boundaries.
